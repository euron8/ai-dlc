## 1. The finding (already established — do not re-derive, but DO verify)

ai-dlc's adversarial **convergence cycle** (Rule 8) has an exit condition of **zero CRITICAL
and zero MAJOR**. It reaches that by dispatching an `adversary` teammate that invokes the
**bmad** skill `/bmad-review-adversarial-general`.

Read that skill: `/Users/n8/git/graph/.claude/skills/bmad-review-adversarial-general/SKILL.md`.
It is **37 lines**, and three of them make convergence impossible:

| line | text |
|---|---|
| Step 2 | *"Find **at least ten issues** to fix or improve in the provided content."* |
| Step 3 | *"Output findings as a Markdown list: descriptions only, **no severity, priority, or ranking**."* |
| HALT CONDITIONS | *"**HALT if zero findings** — this is suspicious, re-analyze or ask for guidance."* |

**The two contracts have no fixed point.** bmad: find ≥10, never zero, grade nothing.
ai-dlc: exit only at zero blocking findings, graded on a CRITICAL/MAJOR/MINOR ladder.
**ai-dlc's entire convergence gate rests on a severity classification that the skill it
invokes is explicitly instructed NOT to produce.** Severity therefore has no source of
truth — it is re-invented from scratch each pass by a fresh context, so the MAJOR count the
gate reads is an unanchored judgment. "Converge to zero MAJOR" may be a fixed point that
does not exist.

**ai-dlc never names this conflict anywhere.** `core/team-roles/adversary.md:45` says "A clean
verdict is a valid outcome", which pushes back on the halt-if-zero rule, but the ≥10 floor and
the no-severity rule are never mentioned or overridden.
