Criterion (a) rubric. The subject is every tracked non-fixture file named on a non-comment line of the fixture's `run.sh` or its sibling scripts (token match on the full path, a path suffix, or a unique basename). The primary subject is the code file with the most references. It REACHES when a gate step or install root reaches it transitively: `.githooks/pre-push` is the gate root, `scripts/install.sh` the install root, `install.sh`'s copy loop ships `core/skills`, `core/team-roles`, `core/hooks`, `core/session-driver`, `core/scripts`, `core/git-hooks`, `core/schemas`, `core/rules`, `core/ci-templates`, `templates` and `patterns`. A code file is reached from a parent only by a CALL (command position or after bash/sh/source/exec/node/python on a line that is not an echo/printf/err message); a data file is reached by any non-comment read. A subject is also EXECUTED when a shipped step, skill or role file (core/skills/**, core/team-roles/**), or the operator rulebook (CLAUDE.md, .claude/rules/*.md, or an action line of a docs/plans file), tells its reader to RUN it in command form; that reach class is OPERATOR-CMD (operator rulebook or plan action line) or STEP-CMD (shipped step/skill/role file), and the verdict is PASS(OPERATOR-CMD) or PASS(STEP-CMD) with the file:line of the instruction. OPERATOR-CMD and STEP-CMD were an OWNER rubric correction (b256-B1 owner), not part of the contract's original (a); a description of a tool, even with its options and exit codes, is not a run instruction (CLAUDE.md:91 describes census-hermetic-coverage.sh that way and it stays FAIL). A fixture is never a reacher and a prose mention that is not a run instruction is not one. Any SKIP or `exit 0` before the first ok is READ. Scan source and the exact patterns are in the fenced block at the end of this section.

Criterion (c) rubric. Scan `run.sh`, sibling scripts and the executed subject scripts for: `sleep`; real-clock reads (`date +%s`, `$SECONDS`, `time.time()`, `date -u` compared numerically); `timeout`, watchdogs, deadlines; background `&` with `wait`; wall-clock windows. Each non-comment hit is read and classed SEAMED (clock or deadline injected, or the interleaving forced), LOAD-DEPENDENT (the verdict can move with load), or NOT-ASSERTED (the hit is text, a fork-join whose order is not asserted, or a path the fixture does not drive). NONE means no hit. Comment-only matches are never counted. The BL-868 class rows of `core/fixtures/fixture-hygiene/receipt-bl868.sh` (W-SLEEP, W-CLOCK, W-TIMEOUT, W-BOUND) are the same rubric applied mechanically to unbounded versus bounded waits; the scan here is independent of them.

Where a fixture only references a subject script that carries a clock or sleep, the row is NOT-ASSERTED with the subject hit named, unless the fixture drives that path with a clock shim (SEAMED) or a count-bounded wait the load can exhaust (LOAD-DEPENDENT).

import os, re, subprocess, collections
# scanlib: the static scan behind docs/analysis/bl915-fixture-audit.md. Run from the repo root (a clean checkout).
EXCL = {'review-shard-merge','review-shard-merge-b','adversarial-shard-merge','backlog-receipt-binding',
        'apply-restamp-worklist','apply-restamp-worklist-b','apply-restamp-worklist-c','ledger-reverify'}
def git(*a):
    return subprocess.run(['git']+list(a), capture_output=True, text=True).stdout
tracked = [t for t in git('ls-files').split('\n') if t]
tset = set(tracked)
fx_all = sorted(os.path.basename(os.path.dirname(p)) for p in tracked if re.match(r'core/fixtures/[^/]+/run\.sh$', p))
fx = [f for f in fx_all if f not in EXCL]
nonfx = [t for t in tracked if not t.startswith('core/fixtures/') and not t.startswith('docs/plans/')]
suf = collections.defaultdict(set)
for t in nonfx:
    parts = t.split('/')
    for k in range(0, len(parts)-1):
        suf['/'.join(parts[k:])].add(t)
base = collections.defaultdict(set)
for t in nonfx:
    base[os.path.basename(t)].add(t)
DATAEXT = re.compile(r'\.(sh|py|js|md|yaml|yml|json|txt|tsv|template)$')
CODE = re.compile(r'\.(sh|py|js)$')
def readf(p):
    try: return open(p, errors='replace').read()
    except Exception: return ''
def noncomment(text):
    return [(i, l) for i, l in enumerate(text.split('\n'), 1) if l.strip() and not l.strip().startswith('#')]
MSG = re.compile(r'^\s*(echo|printf|err|warn|fail|die|note|bad|ok|log|skip)\b')
CMDPOS = re.compile(r'(^|[;&|(`{]|\$\(|\bthen\b|\bdo\b|\belse\b)\s*["\']?[^\s"\']*$')
VERB = re.compile(r'\b(bash|sh|source|exec|node|python3?|nohup|inproc|run|drive)\s+(-[A-Za-z-]+\s+)*["\']?[^\s"\']*$|(^|[;&|(])\s*\.\s+["\']?[^\s"\']*$')
def is_call(line, start):
    # a CALL: the token sits in command position or after an executing verb, on a line that is not a message
    if MSG.match(line): return False
    pre = line[:start]
    return bool(CMDPOS.search(pre) or VERB.search(pre))
def refs_in(text, selfpath=None):
    res = collections.OrderedDict()
    for i, l in noncomment(text):
        for m in re.finditer(r'[A-Za-z0-9_.@+/-]+', l):
            tok = m.group(0).lstrip('/')
            if not DATAEXT.search(tok) and tok != 'pre-push': continue
            cands = set()
            if tok == 'pre-push': cands = {'.githooks/pre-push', 'core/git-hooks/pre-push'}
            elif '/' in tok:
                parts = tok.split('/')
                for k in range(len(parts)-1):
                    s = '/'.join(parts[k:])
                    if s in tset and not s.startswith('core/fixtures/'): cands = {s}; break
                    if s in suf and len(suf[s]) <= 2: cands = set(suf[s]); break
            else:
                b = base.get(tok)
                if b and len(b) == 1 and tok not in ('SKILL.md', 'README.md'): cands = set(b)
            call = is_call(l, m.start())
            for c in cands:
                if c != selfpath:
                    e = res.setdefault(c, [0, i, False]); e[0] += 1; e[2] = e[2] or call
    return res
graph = {}
def edges(p):
    if p not in graph: graph[p] = refs_in(readf(p), p)
    return graph[p]
def reach(roots):
    seen = {r: None for r in roots}; st = list(roots)
    while st:
        n = st.pop()
        if not (CODE.search(n) or n.endswith('pre-push')): continue
        for c, (cnt, ln, call) in edges(n).items():
            if CODE.search(c) and not call: continue   # a code file is reached only by a CALL; a data file by any read
            if c not in seen: seen[c] = (n, ln); st.append(c)
    return seen
gate = reach(['.githooks/pre-push'])
inst = reach(['scripts/install.sh'])
INST = ('core/skills/','core/team-roles/','core/hooks/','core/session-driver/','core/scripts/','core/git-hooks/','core/schemas/','core/rules/','core/ci-templates/','templates/','patterns/')
def reach_of(f):
    if f in gate:
        g = gate[f]
        return 'gate<-%s:%s' % g if g else 'gate root'
    if f.startswith(INST): return 'install-copy:' + ('/'.join(f.split('/')[:2]) if f.startswith('core/') else f.split('/')[0])
    if f == 'scripts/install.sh': return 'install root'
    if f in inst:
        g = inst[f]; return 'install.sh<-%s:%s' % g if g else 'install root'
    return None
CPAT = [
 ('sleep', re.compile(r'(^|[^A-Za-z0-9_-])sleep[ \t]+[0-9$"\'{(]')),
 ('date+%s', re.compile(r'date[^|;&]*\+%s|\bEPOCHSECONDS\b')),
 ('SECONDS', re.compile(r'\$\{?SECONDS\b|\bSECONDS=')),
 ('time.time', re.compile(r'time\.time\(\)|time\.monotonic|Date\.now\(\)|perf_counter')),
 ('timeout', re.compile(r'(^|[^A-Za-z0-9_-])(timeout|gtimeout)[ \t]+[0-9$"\'{(-]|\bwatchdog\b|ulimit -t|\bdeadline\b|\bDEADLINE\b')),
 ('date-cmp', re.compile(r'date -u[^|;]*\)[^|;]*(-gt|-lt|-ge|-le)|\bstat -[fc][ \t]+%[mY]|\bnow=\$\(date')),
 ('bg&', re.compile(r'[^&>|0-9]&[ \t]*($|;|#|\))|^[ \t]*&[ \t]*$|\bwait[ \t]+("?\$|\$!)|\bwait$')),
]
def c_hits(text):
    hits = []
    for i, l in enumerate(text.split('\n'), 1):
        comment = l.strip().startswith('#')
        for name, pat in CPAT:
            if pat.search(l): hits.append((name, i, comment, l.strip()[:150]))
    return hits
def early_exits(rs):
    lines = rs.split('\n'); first_ok = None
    for i, l in enumerate(lines, 1):
        if l.strip().startswith('#'): continue
        if re.search(r'(^|[^A-Za-z_])(ok|pass|PASS)[ \t]+["\'$]|printf[^\n]*  ok  |echo[^\n]*  ok  ', l) and 'ok()' not in l.replace(' ', ''):
            first_ok = i; break
    out = []
    for i, l in enumerate(lines, 1):
        if first_ok and i >= first_ok: break
        s = l.strip()
        if s.startswith('#'): continue
        if re.search(r'\bexit[ \t]+0\b|\bSKIP\b', s): out.append((i, s[:120]))
    return first_ok, out
def scan_fixture(f):
    d = 'core/fixtures/%s' % f
    rs = readf(d + '/run.sh')
    sib = [t for t in tracked if t.startswith(d + '/') and CODE.search(t) and t != d + '/run.sh']
    subj = collections.OrderedDict()
    for p in [d + '/run.sh'] + sib:
        for c, (n, i, call) in refs_in(readf(p), p).items():
            e = subj.setdefault(c, [0, p, i]); e[0] += n
    m = re.search(r'IMPL="\$HERE/\.\./([A-Za-z0-9_-]+)/run\.sh"', rs)
    wrapper = m.group(1) if m and len(rs.split('\n')) < 60 else None
    decl = None
    if os.path.exists(d + '/inputs.decl'):
        decl = [x.strip() for x in readf(d + '/inputs.decl').split('\n') if x.strip() and not x.startswith('#')]
    own = []
    for p in [d + '/run.sh'] + sib:
        for h in c_hits(readf(p)): own.append((p.replace(d + '/', ''),) + h)
    sub = []
    for c, (n, p, i) in subj.items():
        if CODE.search(c):
            for h in c_hits(readf(c)):
                if not h[2]: sub.append((c,) + h)
    first_ok, early = early_exits(rs)
    return dict(f=f, n=len(rs.split('\n')), wrapper=wrapper, decl=decl, own=own, sub=sub,
                subj=[(c, v[0], v[1], v[2], reach_of(c)) for c, v in subj.items()], first_ok=first_ok, early=early)

## Tool

`scripts/kill-matrix.sh --subject <path> [--jobs N] [--sha <rev>] [--out DIR] [--seed S] [--exclude "<fixture> ..."] [--no-verdict "<fixture> ..."] [--timeout SECONDS]`, or `scripts/kill-matrix.sh --self-probe-only [--jobs N] [--out DIR]`, or `scripts/kill-matrix.sh --rescore <run dir>` to re-score a recorded run without running a fixture. Exit 0 means it ran, whatever the verdicts; exit 2 means it could not run. `--exclude` drops fixtures from the run set, so they are not co-killers and UNIQUE is an upper bound against the run set. `--no-verdict` fixtures run and count as co-killers but get no verdict of their own. `--timeout` is the watchdog's wall timeout per run; a run it kills is TIMEOUT and never a kill.

Verdict vocabulary, the unit being the fixture: UNIQUE (conclusive, keep), COVERED-provisional, COVER-RETAINED-provisional (kills, is not UNIQUE, and stays outside the greedy cover set to keep the cover), NOKILL-provisional, NO-VERDICT (a `--no-verdict` fixture) and BROKEN. Run classes: RED-BROKEN (a fixture-level kill on a broken mutant run over a green base: it blocks UNIQUE elsewhere but never makes its own fixture UNIQUE or COVERED), PLAIN-RED (a PLAIN-run red, which blocks UNIQUE but never supplies COVERED), FORK-FAIL and FLAKY (a kill that did not reproduce on re-run; it scores nothing). Refusals: OVERLAY-OPAQUE (the un-overlaid and overlaid base runs differ, so the fixture is not scored and is never a co-killer) and OVERLAY-NOT-SOURCED (a fixture names `lib/mutant.sh` but its overlaid run carries no sourced record). Provisional verdicts are "on 4 sampled sites" and never a failure of (b) by themselves. A kill is classed static-text or behavioural, and every kill is kept as an arm-level row in `kills.tsv`.

Battery isolation is done in the scratch copy only. `core/fixtures/lib/mutant.sh` is rewritten as an overlay that is byte-transparent on stdout and stderr and records through a side file; the tool reads that side file and never fixture output. Every fixture also gets one PLAIN run on the original `lib/mutant.sh`, and a plain run that differs from the overlaid base runs makes the fixture OVERLAY-OPAQUE. Every run's temp, verdict store and side file live under one short root, `mktemp -d /tmp/km.XXXXXX`, because a deep `--out` made sandbox paths too long for a fixture that pads them.

The self-probe runs first on a toy repo and has 31 cases. It also runs deliberately broken scorer and runner variants inside the probe; each case is failed by a named variant, or the tool exits 2. The tool was reviewed by a tip adversary and three delta passes, the last reading no BLOCKER.

The tool is an operator tool: it runs on no gate and no hook, and it is a correctness run that is never timed.

- **Yield bound.** A fixture is UNIQUE (a conclusive keep) only if it is the sole killer of at least one sampled mutant. With 4 mutant sites per subject, a tranche can produce at most 4 UNIQUE fixtures whatever the sample size n, at a cost of about 7 hermetic runs per fixture (2 base, 1 plain, 4 mutant) plus adaptive cells. Yield per run is at most 4/(7n): at most 4 per about 140 runs at n=20, and at most 4 per about 560 at all 80 coverers of `lib.sh`. Adding fixtures adds runs and can only lower the UNIQUE count.

A finite mutant sample can confirm a keep (UNIQUE) but can never prove a fail, because a fixture's unique kill may sit at an unsampled site.
