# scripts/bl868-wait-allowlist.txt -- the allowlist of validate-fixture-hygiene.sh's arm H9 (BL-868: no fixture
# verdict may depend on load). Rows `<path>\t<id>\t<reason>`, one per site. The allowed line ends in a trailing comment
# `# bl868-allow: <id>`, and the row drops every H9 row on THAT line. Keyed on the marker, never on the line's text,
# so an edit that keeps the marker keeps the suppression, and an unmarked identical line is still a row. Each id is
# unique here and must sit on exactly one line of its path; an id on no line or on several is a W-ALLOW-STALE row (a
# FAIL), and so is a marker whose id no row here names, or whose row names another file (it also suppresses
# nothing). A marked line the scan no longer flags is a NOTE on stderr. A malformed or duplicate row refuses the run (exit 2). Every row is a line where no
# elapsed time can decide a verdict; its reason says why. Read from the validator's resolved root; a root without this
# file allows nothing, so every marked site there fires.
