# document-partition

Whether it ships is decided by the absence of a `.dist-only` marker
(`.claude/rules/fixture-ship-decl.md`). It ships: its subject, `partition-document.sh`, is a
core script every consumer has at `scripts/ai-dlc/`. The fixture resolves it by walking up in
either layout.

- `run.sh` — the arms and the mutant battery. Every document is generated inside the run, one
  mktemp world per predicate; the header states which shape separates which mutant.
